# PeLove ♥
Aplicativo demonstrativo de relacionamentos, com identidade romântica e interface adaptada para celulares Android.

## Testar
Abra `index.html` no navegador ou publique a pasta pelo GitHub Pages. A demonstração usa perfis fictícios e grava curtidas, matches, conversas e perfil no armazenamento local do navegador.

## O que funciona nesta versão
- Cards com gesto de deslizar e botões curtir/passar.
- Match demonstrativo entre alguns perfis de exemplo.
- Lista de matches e conversas.
- Chat local com resposta automática de demonstração.
- Edição de nome, idade (18+) e bio, com foto por URL.

## Limitações
Esta é uma versão front-end. Não conecta pessoas reais entre aparelhos, não tem autenticação, moderação, servidor ou mensagens em tempo real. Esses recursos exigem backend e controles de segurança/privacidade antes de um lançamento público.
